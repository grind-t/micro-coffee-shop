# Loyalsuns Support

Переписка с поддержкой Loyalsuns (Hebei Langlichen Electronic Technology)
ведётся через WhatsApp. Скрипты в `scripts/` читают и отправляют сообщения
с помощью CLI `wacli` (уже авторизован, дополнительная настройка не нужна).

## Получить историю переписки

```bash
bun scripts/history.js [limit]
```

- `limit` — максимальное количество сообщений (по умолчанию 20).
- Выводит в stdout JSON-массив сообщений, отсортированный от новых к старым:

```json
[{ "timestamp": "2026-06-01T12:00:00.000Z", "incoming": true, "text": "...", "attachment": "..." }]
```

- `incoming: true` — сообщение от поддержки Loyalsuns (входящее).
- `incoming: false` — наше сообщение поддержке.
- `text` — текст сообщения.
- `attachment` — тип медиафайла, если прикреплён.

## Отправить сообщение поддержке

```bash
bun scripts/reply.js "текст сообщения" [файл1 файл2 ...]
```

- Первый аргумент — текст сообщения.
- Остальные аргументы — пути к файлам, которые будут отправлены отдельными сообщениями.
- Ничего не выводит в stdout — результат это отправленное сообщение.

## Типичный сценарий

1. Запустить `history.js`, чтобы прочитать контекст переписки.
2. Сформулировать ответ и отправить его через `reply.js`.
