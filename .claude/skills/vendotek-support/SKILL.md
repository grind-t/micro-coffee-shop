# Vendotek Support

Переписка с поддержкой Vendotek ведётся по email через тикет-систему Okdesk
(`okdesk@termt.com`). Скрипты в `scripts/` читают и отправляют сообщения через
Gmail с помощью CLI `gws` (уже авторизован, дополнительная настройка не нужна).

## Получить историю переписки

```bash
bun scripts/history.js [limit]
```

- `limit` — максимальное количество писем (по умолчанию 50).
- Выводит в stdout JSON-массив сообщений, отсортированный от новых к старым:

```json
[{ "date": "2026-06-01T12:00:00.000Z", "inbound": true, "text": "..." }]
```

- `inbound: true` — сообщение от поддержки Vendotek (входящее).
- `inbound: false` — наш ответ поддержке.
- `text` — текст сообщения без цитат, подписей и служебного мусора.
- Письма с пустым текстом в результат не попадают.

## Отправить ответ поддержке

```bash
bun scripts/reply.js "текст ответа" [файл1 файл2 ...]
```

- Первый аргумент — текст ответа.
- Остальные аргументы — относительные пути к файлам, которые будут прикреплены к письму.
- Отвечает на последнее письмо, полученное от `okdesk@termt.com`.
- Ничего не выводит в stdout — результат это отправленное письмо.

## Типичный сценарий

1. Запустить `history.js`, чтобы прочитать контекст переписки.
2. Сформулировать ответ и отправить его через `reply.js`.
