# Универсальный зерновой кофе HoReCa для разных напитков

## Параметры

Обжарка: средняя/средне-темная, со стабильным вкусом в каждой партии
Структура:
Основа (40–50%): Бразилия натуральная — сладость, тело, шоколад, стабильность
Баланс (20–30%): Колумбия мытая — чистота, лёгкая кислотность, элегантность
Сложность (опционально 10–20%): Гватемала / Коста-Рика / Гондурас — глубина, тело, фруктовость
Характер (опционально, 5–15%): Эфиопия натуральная — ягодная сладость, «вау-фактор»
Крема (10–20%): Индия Cherry AA / Уганда мытая — обязательно мытая робуста
Избегать: Кения (слишком яркая), Вьетнам (низкое качество робусты), Йемен (нестабильность), премиум-моносорта (Geisha, Kona — нет смысла)
